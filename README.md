# 会话数据分析平台

> AI 对话质量监控与数据可视化工具，无需后端，打开即用。

## 功能概览

### 📊 数据统计看板
- **KPI 总览**：总提问次数、独立用户数、平均响应耗时、用户好评率
- **助手调用分布**：柱状图展示各助手被调用的次数对比
- **TOP 10 用户提问排名**：识别最活跃的用户群体
- **TOP 30 高频关键词**：从用户提问中提炼高频词汇
- **TOP 30 高频会话标题**：统计同类会话的重复度，洞察常见诉求
- **用户提问词云**：可视化关键词权重分布

### 💬 会话回放查询
- 按会话ID 聚合消息，还原完整对话流程
- 支持多关键词搜索（`/` 分隔），快速定位目标会话
- 点击统计图表条目可自动跳转至相关会话
- 显示响应耗时、助手名称、用户信息等元数据

### 📋 全量提问浏览
- 展示所有用户问题，支持关键词筛选
- 分页加载（每页 50 条），支持直接跳转至对应会话
- 表格呈现：用户名、助手、提问内容、时间

### 🗄️ 多数据集管理
- 支持同时保存多份数据集到浏览器本地存储（`localStorage`）
- 一键切换/删除历史数据集，无需重复上传
- 展示数据集名称、导入时间、记录条数

### 🛠️ JS 脚本生成器
- 输入目标页面 URL 和日期范围，自动生成数据抓取脚本
- 生成的脚本可在浏览器控制台执行，将 AI 会话数据导出为 Excel
- 内置字符长度限制（≤30,000）防止 Excel 单元格溢出

## 快速开始

本项目为纯前端单文件应用，**无需任何安装或服务器**。

```bash
# 克隆项目
git clone https://github.com/hanfsw/chat-report.git
cd chat-report

# 用浏览器直接打开
open index.html
```

或者直接将 `index.html` 拖拽到浏览器中即可使用。

## 数据格式

上传的 Excel 文件（`.xlsx` / `.xls`）应包含以下字段（列名需与此一致）：

| 字段名 | 说明 | 是否必填 |
|---|---|---|
| `会话ID` / `Session ID` | 唯一标识同一轮会话 | ✅ |
| `用户问题` | 用户的提问内容 | ✅ |
| `AI回答文本` / `AI回答` | AI 的回复内容 | ✅ |
| `助手名称` | AI 助手的名称 | 推荐 |
| `用户名` | 提问用户的名称或 ID | 推荐 |
| `会话标题` | 会话的标题 | 推荐 |
| `对话时间` / `开始时间` | 消息发送时间 | 推荐 |
| `耗时(秒)` | AI 响应耗时 | 可选 |
| `满意度` | 用户评价，值为 `赞` 时计入好评 | 可选 |

## 技术栈

| 类别 | 技术 |
|---|---|
| 框架 | [Vue 3](https://vuejs.org/)（CDN，无构建） |
| 样式 | [Tailwind CSS](https://tailwindcss.com/)（CDN） |
| 图表 | [Apache ECharts 5](https://echarts.apache.org/) + [echarts-wordcloud](https://github.com/ecomfe/echarts-wordcloud) |
| 表格解析 | [SheetJS (xlsx)](https://sheetjs.com/) |
| 存储 | 浏览器 `localStorage` |
